# Rà soát & cập nhật nội dung theo mục tiêu README

Mốc hiện tại: **2026-11-21** (mốc trước: `2026-10-06`). Phạm vi: toàn bộ **24 chương nội dung**, `README.md`, cấu trúc mục lục H2–H4, liên kết chéo, kiểm chứng thực nghiệm các hành vi runtime trên **Node v26.5.0** và cập nhật trạng thái **Node.js 26 Active LTS ("Lithium", từ 2026-10-28)** + **TypeScript 7.0**.

Đợt cập nhật **2026-11-21** giải quyết triệt để 4 nhóm công việc:
1. **Vá lỗi kỹ thuật nghiêm trọng (P0) & đồng bộ LTS:** sửa hơn 35 sai sót về spec/runtime/TS 7 và bug chạy sai trong code mẫu (vòng lặp vô hạn, pipe deadlock, respawn vô hạn, đảo ngược `SuppressedError`, sai thứ tự `nextTick` ở ESM top-level, JSON modules bị ghi nhầm là frozen, `O_NOFOLLOW === undefined` trên Windows, dual-package `exports` chết nhánh `require.types`, `baseUrl` hard error trên TS 7...).
2. **Cập nhật API Node 26 + TS 7 + ES2025/2026 & chuẩn erasable:** bổ sung các tính năng nền tảng (`Error.isError`, `import.meta.main`, `AsyncContextFrame`, `DisposableStack`, `FileHandle[Symbol.asyncDispose]`, `Float16Array`, `Uint8Array` Base64/Hex, `JSON.rawJSON`, `fs.glob`, `crypto.argon2`/`hash`, `WebSocket`, `zlib` `zstd`, `node --build-sea`, cờ song song TS 7 `--checkers`/`--builders`/`--singleThreaded`, `"lib": ["ES2025", "ESNext.Temporal"]`) và loại bỏ parameter properties khỏi ví dụ thông thường.
3. **Mở rộng full độ sâu 3 chương mới (`testing.md`, `diagnostics.md`, `security.md`):** nâng từ mức outline ~8.5–9 KB (0 H3) lên **79–94 KB mỗi chương** với đầy đủ H2/H3, bảng quyết định, ví dụ Đúng/Sai và test thực thi.
4. **Dọn cấu trúc & tăng độ phủ test tự động:** sửa bảng vỡ, loại bỏ đoạn lặp và mục bị nhồi nhét ở cuối chương, mở rộng `tests/reference-examples.test.mjs`.

## Nguồn và giới hạn xác minh

Phiên bản được đối chiếu với [Node 26.0 release](https://nodejs.org/en/blog/release/v26.0.0/), [lịch Node Release](https://github.com/nodejs/Release/blob/main/schedule.json) (Node 26 vào Active LTS từ `v26.13.0` ngày 2026-10-28), [Node API docs](https://nodejs.org/api/), [TS 7.0 release](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/), [TS 6 migration](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-6-0.html) và [TSConfig erasableSyntaxOnly](https://www.typescriptlang.org/tsconfig/erasableSyntaxOnly.html).

Môi trường kiểm tra cục bộ chạy **Node v26.5.0** (V8 `14.6.202.34-node.24`, Undici `8.7.0`, SQLite `3.53.3`), chưa cài compiler TS 7 native tại máy; các hành vi runtime, API Node 26 mới (`Temporal`, `Map.prototype.getOrInsertComputed`, `Iterator.concat`, `Error.isError`, `RegExp.escape`, `Float16Array`, `Uint8Array.fromBase64`, `crypto.argon2`, `fs.glob`, `v8.startCpuProfile`, `diagnostics_channel.boundedChannel`, `import.meta.main`, `process.loadEnvFile`) và các ví dụ trích xuất đều được xác minh trực tiếp trên Node v26.5.0; các cờ/mặc định TS 7 được đối chiếu với tài liệu phát hành chính thức. Các đoạn ví dụ còn lại mang tính minh họa khái niệm (dùng biến/factory giả định) không được chạy toàn bộ qua `tsc`.
